# Adapter 自动初始化

## 问题

`UClothDeformerComponent` 持有 `TUniquePtr<FInputAdapterBase> InputAdapter` 成员（`ClothDeformerComponent.h:90`），但从未被创建和初始化。`TickComponent()` 中直接调用 `InputAdapter->ExtractInputs(DeltaTime)`（`ClothDeformerComponent.cpp:163`）会导致空指针崩溃。

## 修改文件

只涉及 **1 个 .cpp + 0 个 .h**：

- `Source/Cloth/Private/ClothDeformerComponent.cpp` — 3 处改动
- `Source/Cloth/Public/ClothDeformerComponent.h` — 无需改动（已有 `InputAdapter` 声明和 include）

## 具体变更

### 1. 添加 include（cpp 文件头部）

在 `#include "Components/DynamicMeshComponent.h"` 之后添加：

```cpp
#include "SnugInputAdapter.h"
```

### 2. BeginPlay() — 创建并初始化 InputAdapter（cpp:34-49）

在 `Super::BeginPlay()` 之后、`Initialize()` 之前插入：

```cpp
// 创建输入适配器
InputAdapter = MakeUnique<FSnugInputAdapter>();
if (USkeletalMeshComponent* SkelComp = GetOwner()->FindComponentByClass<USkeletalMeshComponent>())
{
    InputAdapter->Initialize(SkelComp);
}
else
{
    UE_LOG(LogTemp, Warning, TEXT("ClothDeformerComponent: No SkeletalMeshComponent found on owner"));
}
```

完整 `BeginPlay()` 变为：

```cpp
void UClothDeformerComponent::BeginPlay()
{
    Super::BeginPlay();

    InputAdapter = MakeUnique<FSnugInputAdapter>();
    if (USkeletalMeshComponent* SkelComp = GetOwner()->FindComponentByClass<USkeletalMeshComponent>())
    {
        InputAdapter->Initialize(SkelComp);
    }
    else
    {
        UE_LOG(LogTemp, Warning, TEXT("ClothDeformerComponent: No SkeletalMeshComponent found on owner"));
    }

    UE_LOG(LogTemp, Log, TEXT("Cloth Deformer Component BeginPlay - attempting to initialize model..."));
    if (Initialize())
    {
        UE_LOG(LogTemp, Log, TEXT("Cloth Deformer Component initialized successfully"));
    }
    else
    {
        UE_LOG(LogTemp, Warning, TEXT("Cloth Deformer Component initialization failed - no model asset specified"));
    }
}
```

### 3. EndPlay() — 清理 InputAdapter（cpp:50-56）

```cpp
void UClothDeformerComponent::EndPlay(const EEndPlayReason::Type EndPlayReason)
{
    InputAdapter.Reset();
    modelInstance_.Reset();
    Super::EndPlay(EndPlayReason);
}
```

### 4. Reset() — 同时重置 Adapter 状态（cpp:134-139）

```cpp
void UClothDeformerComponent::Reset()
{
    if (InputAdapter.IsValid())
    {
        InputAdapter->Reset();
    }
    modelInstance_.Reset();
    bIsInitialized = false;
    UE_LOG(LogTemp, Log, TEXT("ONNX Component reset"));
}
```

### 5. TickComponent() — 添加空指针保护（cpp:162）

```cpp
if (!InputAdapter.IsValid())
{
    return;
}
TMap<FString, TArray<float>> ModelInputs = InputAdapter->ExtractInputs(DeltaTime);
```

## 边界情况处理

| 场景 | 行为 |
|------|------|
| Actor 无 SkeletalMeshComponent | 日志警告，TickComponent 跳过推理 |
| Initialize() 失败（无 ModelAsset） | 不影响 Adapter 创建，但推理跳过 |
| 运行时切换 SkeletalMesh | 需额外调用 `InputAdapter->Initialize(NewMesh)` — 不在本次范围 |

- `FSnugInputAdapter` 构造函数零参数，无额外初始化需求
- `FInputAdapterBase` 接口已完备
- 不涉及其他文件修改
