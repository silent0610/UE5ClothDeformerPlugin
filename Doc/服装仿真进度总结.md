## 2 计划

**P0**

- [ ] 完成 GPU 变形闭环 — 在 Optimus 中实现 ComputeShader 节点消费 OffsetBufferSRV, 或将偏移通过 USkinnedMeshComponent 路径应用到网格顶点
- [ ] Adapter 自动初始化 — BeginPlay 中创建 FSnugInputAdapter 并调用 Initialize(GetSkeletalMesh()), 防止空指针崩溃

**P1**

- [ ] 激活并验证坐标系转换 — 打开 ConvertBoneRotation 调用, 与 Python 训练输出的 Axis-Angle 数据比对确认转换正确性
- [ ] 单元测试覆盖 — 为 FSparseMappingMatrix::ApplyMapping 和 FOnnxModelInstance::Run 编写回归测试
- [ ] FSurfaceProjection 补全 — 将 AABB 树投射的 BuildMappingMatrix 结果接入 GenerateMapping 完整流程

**P2**

- [ ] 异步 Bake + 进度条 — FAsyncTask 封装耗时映射计算
- [ ] 自动保存资产 — Bake 后调用 UEditorLoadingAndSavingUtils::SavePackages
- [ ] 多动态维度支持 — 扩展 CalculateInputTensorDimensions 支持多个 -1 维度
- [ ] 单精度全流程 — 将 ApplyMapping 输出类型改为 TArray<FVector3f>, 移除每帧类型转换

**P3**

- [ ] 资产自动导入工具 — 实现 Asset Action, 允许右键 .onnx → 创建 ModelAsset
- [ ] 跨平台支持 — Android/iOS ONNX Runtime 交叉编译, GPU delegation (NNAPI/OpenCL)
- [ ] 多 LOD 支持 — 为不同 LOD 级别准备不同精度的映射矩阵
- [ ] 性能 Dashboard — 运行时监控推理延迟、映射耗时、GPU 上传带宽的可视化工具
