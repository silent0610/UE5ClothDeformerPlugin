# 需求分析

## 0.1 需求整理

- ***不是网易方面要求，只是我们自己测试用***
- 作为独立的 UE5 插件
- 能够加载和推理 ONNX 模型
- 模型以 [[SNUG.md|SNUG]] 为基准
- 为低模与高模 服装建立映射关系
- 根据映射关系, 将模型输出的低模顶点偏移 应用到高模上
- **性能要求极高**, 但是具体有多高?
- 完善的 UI
- 在 UE5 内, 对于给定的低模与高模 (拖入面板), 通过按钮构建映射
- 模型的输入 $\beta$ (体型) 和 $\theta$ (动作) 绑定到 UE5 的 `SkeletalMeshComponent` 自动提取, 暂定
- 模型应当作为 asset 被导入模型, 插件面板只接受 asset 加载模型
- 模型 asset 中应当保存字节流
- 高模顶点的更新方式? **是否需要通过 ComputeShader 进行顶点更新?** 还是只在 CPU 端更新? **先 CPU 吧**, 直接更新顶点
- 目标平台? 仅限 Windows (PC)？是否需要支持 Android/iOS 或 主机 (PS5/Xbox)？（这直接决定了 DLL 的加载方式和 ONNX 库的体积控制）, **先只考虑 windows, 后续再考虑其他平台**
- 当角色 瞬移 时, 上一帧的速度 $v$ 和隐藏状态 $h$ 会导致巨大的错误形变。可能需要提供一个 `ResetState()` 接口来瞬间清空记忆？
- 关于映射策略? KNN 是否足够? 还需要实现哪些? 先按 KNN 来
- 统一坐标系, 训练和应用必须统一, 或者能够处理这种变化
- 插件应介于 UE5 **动画系统** 和**渲染管线**之间, 插件从动画系统获取角色的体型数据, 骨骼位姿, 速度等
- 系统内部维护 ONNX session, 存储上一帧所需信息, 建立映射, 执行推理并将 onnx 模型输出的顶点偏移 映射到高模.
- **时间**
