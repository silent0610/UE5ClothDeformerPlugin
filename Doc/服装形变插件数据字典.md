# 数据字典

| **数据项**          | **类型**                    | **说明**                                   | **来源**              |
| ---------------- | ------------------------- | ---------------------------------------- | ------------------- |
| **Betas**        | `float[10]`               | 体型参数                                     | 用户配置 / 动画蓝图         |
| **Pose**         | `float[72]`               | 72个旋转参数 (Axis-Angle)                     | `SkeletalMesh` 骨骼转换 |
| **Velocity**     | `float[3]`                | 根骨骼全局速度                                  | Actor Velocity      |
| **HiddenState**  | `TArray<float>` 或者 Tensor | 循环神经网络记忆单元                               | 内部自维护 (上一帧输出)       |
| **MappingData**  | `Struct`                  | 包含 `Indices (int32)` 和 `Weights (float)` | 编辑器烘焙生成             |
| **OffsetStream** | `TArray<FVector>`         | 顶点位置偏移量                                  | 模型输出 -> 映射计算        |
