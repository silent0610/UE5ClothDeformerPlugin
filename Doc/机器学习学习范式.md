# 机器学习学习范式

| **学习类型**  | **数据情况**       | **核心目标**  | **老师（监督信号）在哪里？** | **典型例子**                          |
| --------- | -------------- | --------- | ---------------- | --------------------------------- |
| **监督学习**  | 全部有标签          | 预测结果      | 老师直接给答案          | Loss = \|true - my\|              |
| **无监督学习** | 全部无标签          | 寻找结构/聚类   | 没有老师，自己悟         | 用户画像聚类                            |
| **半监督学习** | 少量有标签 + 大量无标签  | 结合两者提升性能  | 老师教一点，剩下自己悟      | 只有少量标注的CT片                        |
| **自监督学习** | 无人工标签 (利用数据自身) | 学习数据的特征表示 | 课本本身就是老师 (完形填空)  | 人类负责制定“物理规则/公式”，模型负责“寻找符合这些规则的解”。 |
| **强化学习**  | 状态+动作+奖励       | 寻找最优策略    | 现实结果给反馈 (奖励/惩罚)  | 训练AI打王者荣耀                         |
